## 題目

- 來源：LeetCode 739. Daily Temperatures（https://leetcode.com/problems/daily-temperatures/）
- 敘述：給一個整數陣列 `temperatures`，代表每天的溫度。回傳陣列 `answer`，`answer[i]` 是第 i 天之後要再等幾天才會遇到更暖的溫度；如果之後都沒有，`answer[i] = 0`。
- 範例：`[73, 74, 75, 71, 69, 72, 76, 73]` → `[1, 1, 4, 2, 1, 1, 0, 0]`

## 解法

- 思路：單調遞減堆疊。堆疊只存還在等更暖日子的 index。新的一天比頂端暖，就 pop 頂端並寫入答案。
- 重點（第 4 幕要教的不變量）：堆疊從底到頂一定是遞減，不需要另外排序。
- 時間：`O(n)`，每一天最多 push 一次、pop 一次
- 空間：`O(n)`，溫度一路下降時所有天都留在堆疊
- 程式碼（影片上顯示的版本，第 3 幕直接使用）：

```python
result = [0] * len(temperatures)
tmp = []
for i1, temp1 in enumerate(temperatures):
    while tmp and temp1 > temperatures[tmp[-1]]:
        i2 = tmp.pop()
        result[i2] = i1 - i2
    tmp.append(i1)
return result
```
